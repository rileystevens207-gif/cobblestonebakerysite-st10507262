# Cobblestone Bakery Website

A responsive website for Cobblestone Bakery, a fictional Cape Town bakery, built as part of the WEDE5020 Portfolio of Evidence.

## Project Overview

This project is a multi-page website (Home, About Us, Products, Enquire, Contact) built with HTML, CSS, and JavaScript, developed across three parts: HTML foundation, CSS styling and responsive design, and interactive functionality.

## Changelog

### 18 September 2026
- Created external stylesheet (`style.css`) linked to all five HTML pages.
- Added CSS reset and base styles (box-sizing, font-family, colour variables for white/brown palette).
- Applied typography: Playfair Display (Google Fonts) for headings, Georgia for body text, using rem units.
- Built header layout using Flexbox (logo and nav side-by-side).
- Built product page layout using CSS Grid (Bread, Pastries, Cakes in a 3-column grid).
- Added hover, focus, and active pseudo-class states for buttons and navigation links, including visible focus outlines for accessibility.
- Added responsive breakpoints at 768px and 480px using media queries (product grid collapses from 3 to 2 to 1 column; header stacks on smaller screens).
- Implemented responsive images using `srcset` and `sizes` on the hero image, with resized versions (480w, 800w, 1200w).
